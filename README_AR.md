# مكتبتي الإبداعية — مشروع Android 1.0

هذا هو **المشروع المصدري الكامل** لتطبيق Android، وليس APK جاهزاً. يتضمن التطبيق واجهة الويب داخل غلاف Android WebView، مع دعم اختيار الصور من الهاتف ونسخ النصوص إلى الحافظة.

## فتح المشروع وبناء APK

1. فك ضغط الملف بالكامل على كمبيوتر.
2. ثبّت Android Studio بإصدار حديث.
3. افتح مجلد `creative_library_android_project` من Android Studio.
4. انتظر Gradle Sync، واسمح بتنزيل مكونات Android SDK المطلوبة (Android SDK Platform 35 و Build Tools المناسبة).
5. من القائمة اختر **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. بعد نجاح البناء ستجد APK غالباً في:
   `app/build/outputs/apk/debug/app-debug.apk`
7. انقل APK إلى هاتف Android وثبّته. قد تحتاج للسماح بالتثبيت من هذا المصدر.

## بناء APK عبر GitHub Actions

ارفع محتويات هذا المشروع إلى مستودع GitHub. سير العمل الموجود في `.github/workflows/build-apk.yml` يبني نسخة Debug APK تلقائياً عند كل Push، ثم يرفقها كـ Artifact باسم `creative-library-debug-apk` في صفحة Actions.

## ما الذي تتضمنه النسخة

- إضافة تصميم أو مرجع أو أمر نصي.
- إرفاق صورة من الجهاز.
- حفظ العناصر محلياً داخل بيانات التطبيق.
- تعديل العناصر وحذفها والبحث والنسخ.
- إنشاء مجموعات.
- تصدير واستيراد نسخة JSON احتياطية.

## تنبيه مهم عن البيانات والسحابة

هذه النسخة تحفظ البيانات محلياً على الجهاز، وتوفر تصدير/استيراد يدوي للنسخة الاحتياطية. **المزامنة السحابية التلقائية لم تُنفّذ بعد**؛ تحتاج في إصدار لاحق إلى خدمة خلفية وحساب/تسجيل دخول وقواعد مزامنة. لا تعتبر التصدير اليدوي مزامنة تلقائية.

## كيف تنقل المشروع إلى محادثة أو حساب آخر؟

أرسل ملف ZIP كاملاً إلى المحادثة الجديدة، ثم انسخ لها النص التالي:

> أريد متابعة تطوير تطبيق Android اسمه «مكتبتي الإبداعية». هذا هو المشروع المصدري الكامل. اقرأ README_AR.md وافحص بنية المشروع وملفات Kotlin وHTML قبل التعديل. حافظ على الوظائف الحالية، ولا تحذف أو تستبدل أي ميزة دون طلبي. عند كل تحديث أعطني الملفات المعدلة كاملة أو ZIP جديداً، واشرح طريقة بناء APK. اعتبر هذا المجلد هو المصدر الأساسي للمشروع.

## بنية مختصرة

- `app/src/main/java/.../MainActivity.kt`: كود Android الأصلي.
- `app/src/main/assets/www/index.html`: واجهة التطبيق ومنطق الوظائف.
- `app/src/main/AndroidManifest.xml`: إعدادات التطبيق.
- `app/build.gradle.kts`: إعدادات بناء Android.
- `.github/workflows/build-apk.yml`: بناء تلقائي على GitHub.

## ملاحظات تقنية

- الحد الأدنى المدعوم: Android 6.0 (API 23).
- Target SDK: 35.
- اسم الحزمة: `com.creativelibrary.app`.
- رقم الإصدار: 1.0 (versionCode 1).
- هذا مشروع بداية قابل للتطوير، ويحتاج اختباراً على جهازك قبل اعتباره إصداراً نهائياً.
